Introducing Grok Bot

Create bots for jobs

One teammate per job — not a single generic chat.

Message like teammates

Talk to them in a thread. They talk back, then go do the work.

Memory

Bots keep context and get sharper the more you work with them.

Log into tools

Gmail, Slack, Calendar, the web — they use them like you do.

Routines

Set a clock. They run overnight, on weekdays, or every hour.

Share

Hand a bot to a classmate in one click. The job travels with it.

Not another chatbot. Agents with computers: jobs, messages, memory, logins, routines, share. Demo the app if the room is with you; otherwise keep moving.
